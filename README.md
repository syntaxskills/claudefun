# ClaudeFun

Fancy and fun Claude configuration packs by SyntaxSkills.

Current packs:

- Good Statusbar
- Funny Spinner Verbs
- Corporate Nonsense Spinner

## Development

```bash
bun install
bun run dev
```

## Maintenance

For isolating uncommitted i18n/default-localized routing work from another
checkout, see [docs/maintenance/i18n-routing-packaging.md](docs/maintenance/i18n-routing-packaging.md).

## Build

```bash
bun run build
```

## Deploy

```bash
bun run deploy
```
